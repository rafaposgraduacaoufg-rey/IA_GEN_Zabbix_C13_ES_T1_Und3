# Contribuindo

Contribuições são bem-vindas para ampliar os cenários de testes de integração e a cobertura do projeto.

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para a alteração.
3. Adicione ou ajuste cenários, prompts ou casos de teste.
4. Documente as mudanças relevantes.
5. Abra um pull request com descrição clara do objetivo.

## Estilo de contribuição

- mantenha o conteúdo em português;
- preserve o foco em testes de integração, contratos e observabilidade;
- documente o caso de uso e o impacto esperado.
